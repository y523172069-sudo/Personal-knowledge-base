# W1 踩坑记录

> 来源：原 `学习进度/测试自动化学习进度.md`「过程中踩过的坑（可复用经验）」，2026-09-28 原样迁入

| 现象 | 原因 | 处理 |
|---|---|---|
| `No module named 'playwright'` | 依赖没装进当前 .venv | `python -m pip install ...`，先用 `sys.executable` 确认解释器 |
| `playwright install chromium` 无输出 | 浏览器已下载过（在 %LOCALAPPDATA%\ms-playwright） | 用一行启动脚本验证 `chromium ok` |
| 识别到的是登录页 | 脚本每次开全新浏览器，没有登录态 | save_login.py 保存 auth.json |
| 登录后进了首页而不是收银台 | 网站登录后默认跳首页 | save_login.py 登录后自动重新打开目标地址再保存 |
| 知识库 README 写 `--yaml`，实际报错 | 自动化框架/conftest.py 只注册了 `--md` | 用 `--md`；handler 按 YAML 文件名匹配 |
