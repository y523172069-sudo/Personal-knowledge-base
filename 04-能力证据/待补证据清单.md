# 待补证据清单

用途：集中追踪会影响简历、述职和 Demo 可信度的证据缺口。这里不写“希望如此”的结果，只记录还需要补什么材料、为什么需要补、当前状态是什么。

状态口径：

- `待补`：还没有材料；
- `待确认`：有口头信息或初步记录，但缺可验证材料；
- `已补待整理`：材料已经存在，但尚未转化到复盘 / 证据索引 / 简历素材；
- `可关闭`：已补齐并同步到对应资产。

## 每周维护时的处理规则

1. 先看 P0，有新材料就优先补进证据索引和简历素材池；
2. P1 主要服务述职和面试复盘，不强行包装成简历成果；
3. P2 只在材料足够具体时整理，否则保留在收集箱；
4. 所有截图、原始数据和内部文件先放入 `04-能力证据/原始材料-仅本地/` 或 `01-收集箱/待整理原始材料/`；
5. 进入简历、Demo 或作品集前必须脱敏，不能直接引用公司内部材料。
