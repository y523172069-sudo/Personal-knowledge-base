# Demo 选题池

Demo 应展示你对真实工作问题的理解，以及将问题转化为解决方案的能力。不要直接复制公司内部系统或敏感数据。

## 推荐顺序

1. 管培生成长证据库：最贴近当前求职目标，数据完全可控，也能展示完整项目闭环；
2. 真需求与最小试点工作台：直接回应“项目落地能力”的职业定位；
3. AI 产品使用分析看板：适合展示数据分析，但必须全部使用合成数据；
4. 企业服务能力认证工作台：业务特色强，但公开规则重建成本较高；
5. 课程试点运营台：作为产品运营方向的补充选题；
6. 海外销售线索跟进台：更偏销售支持，只有补充真实漏斗数据后才值得推进。

## 选题判断标准

- 问题来自真实场景，而不是为了使用某项技术硬凑；
- 能在较短时间内做出完整闭环；
- 能清晰说明目标用户和价值；
- 不包含公司机密、客户信息或不可公开的数据；
- 与目标岗位需要的能力有直接关系。
