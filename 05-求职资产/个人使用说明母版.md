# 个人使用说明母版

状态：访谈中
创建日期：2026-07-06
用途：沉淀“我是什么人、我适合什么环境、我能带来什么、如何更好地与我协作”的表达母版。后续可拆成自我复盘版、内部协作版和外部面试版。

## 1. 当前核心表达

> 我不是能力差，而是不适合长期处在没有边界、没有目标、没有合理路径的环境里。
> 当任务目标清楚、评价标准明确，并且有基本协作路径时，我能够稳定投入、主动拆解问题并形成可交付成果。

## 2. 当前能力画像

当前不是“单点极强型”，更接近“业务理解 + 沟通协作 + 学习吸收驱动的综合型”。

| 能力层级 | 能力 |
| --- | --- |
| 明显优势 | 客户沟通、学习能力、业务理解 |
| 较强能力 | 跨部门协作、海外沟通 |
| 稳定可用 | 结构化分析、项目推进、调研、数据分析、PPT 汇报、复盘、AI 工具使用 |
| 正在补强 | 产品思维 |

## 3. 最容易发挥的任务类型

> 目标清楚，但路径需要我自己拆解。

补充说明：

- 不需要别人把每一步都安排好；
- 需要知道任务为什么做、最终要交付什么、判断好坏的标准是什么；
- 在目标和边界清楚时，可以主动拆路径、做调研、整合信息并形成可交付成果。

## 4. 最容易受挫的工作环境

> 我最容易受挫的环境，不只是任务困难，而是找不到问题根因，也没有改变路径。

具体表现：

- 问题反复出现，但没人愿意定义问题；
- 只有执行要求，没有原因拆解；
- 没有反馈机制，也没有调整机制；
- 无法判断自己哪里做得不好、下一步如何变好。

## 5. 待补问题

后续继续补充：

1. 如果一个 Leader 想用好你，应该怎么给你任务？
2. 你希望未来别人用哪句话记住你？

## 6. 使用边界

- 自我复盘版可以保留真实情绪；
- 内部协作版应强调“如何用好我”和“我能稳定产出的条件”，避免表达成抱怨；
- 外部面试版应强调能力、证据和岗位适配，不直接描述内部委屈。
