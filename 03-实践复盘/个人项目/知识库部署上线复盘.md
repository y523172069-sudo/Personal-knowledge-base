更新日期：2026-11-02

来源或证据：2026-07-31 至 2026-08-03 本人与 AI 协作部署时的对话记录；当时形成的 W2 复盘文档（本地）

## 背景与目标

- 本人想转向 FDE（前沿部署工程师）方向，阶段目标是「最起码知道怎么在外部环境中部署 AI 产品」。
- 第一个练手项目选的是自己日常工作中的一个具体麻烦：把个人知识库部署到自己租的服务器上。
- 技术学习顺序决定先从前端开始；Markdown 转网站选用现成的静态站点生成器，先把部署跑通，不自己写渲染。
- 服务器放海外（免备案），选腾讯云轻量应用服务器（Ubuntu 24.04）。
- 本人决定上线的网站不放求职相关内容。

## 过程

| 日期 | 阶段 | 做了什么 | 结果 |
| --- | --- | --- | --- |
| 07-31 | 阶段 0 | 本机装好 Python 和 mkdocs-material，用 `mkdocs new` 生成测试站点 | 浏览器打开 `localhost:8000` 成功 |
| 08-03 | 阶段 1：本地站点 | `mkdocs.yml` 放在知识库外面，`docs_dir` 指向知识库根目录，用排除规则屏蔽求职资产、Demo 项目、Office 附件和「仅本地」目录 | 第一次构建时发现约 45.8MB 的内部 PPT / Excel 被打包进站点，补排除规则后降到约 1.3MB；求职内容未泄漏 |
| 08-03 | 阶段 1：修链接 | 删掉根目录 3 个 0 字节的 md；把知识库地图里的 Windows 绝对路径改为「`/` 开头 + 去掉 `.md`」 | 构建后失效链接为 0 |
| 08-03 | 阶段 1：传到服务器 | 本地打包上传后解压 | PowerShell 的 `Compress-Archive` 打出的 zip 在 Linux 上解压会因反斜杠路径和 GBK 文件名乱码，改用 Python 脚本逐条替换反斜杠后解压才正常 |
| 08-03 | 阶段 1：Nginx | 配置 `listen 80`、`charset utf-8`、`server_name _`，启用站点并删除默认站点 | 服务器内部 `curl` 返回 200 |
| 08-03 | 阶段 1：外网访问 | 公司网络无法连 SSH(22)，先用腾讯云网页终端登录；用全球节点检测工具测试 | 海外节点返回 200，但中国大陆侧（公司网络与手机流量）ping / 22 / 80 全部不通 |
| 08-03 | 阶段 1：换 IP | 更换服务器公网 IP | 公司网络下 80 和 22 都能连通，说明原 IP 被大陆阻断；服务器配置无需改动 |
| 08-03 | 阶段 1：SSH | 用 `icacls` 修好 Windows 私钥文件权限 | 第一次用 SSH 连上服务器 |
