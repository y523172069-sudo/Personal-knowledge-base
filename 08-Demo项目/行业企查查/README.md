## 任务事实

- 起因：本人向领导汇报部署学习进展后，领导要求本人做一个 Demo。
- 依据：本人提供的立项书《企业大数据征信查询平台项目立项说明》，项目名「行业企查查」，申报部门为风控部。本人确认它和公司正在做的「AI 风险识别官」是同一件事。
- 本人想做的形态：一个可点击的原型，嵌在公司官网里，从导航页点进去。
- 演示目的：让领导看看本人的能力；不考虑评审场景。
- 演示方式：本人当面讲，在旁边边点边说，不是发链接让领导自己看。

## 设定与决定（本人确认）

| 事项 | 决定 |
| --- | --- |
| 对外口径 | 「用 AI 生成结构化的企业信用报告和评分」，不用「法务大模型」的说法 |
| 卖点 | 信息查询、信任分数、AI 报告三个都做，按「最简单、最容易实现」的顺序推进 |
| AI 在产品中承担的事 | 写报告、算分数、做风险判断；现阶段只做原型，不管背后的技术实现路径 |
| 信任分数的维度 | 暂时搁置，之后再讨论 |
| 演示数据 | 本人提供真实材料（企业信息来源 + 公司内部数据），三家公司分别代表优质 / 有风险 / 海外 |
| 海外企业数据维度偏少 | 现实短板，Demo 中不体现 |
| 公司名称 | Demo 中可以用真名，不必脱敏 |
| 工商信息区 | 照编完整数据，演示时口头说明「工商数据接口未接入，此处为示意」 |
| 数据来源标注 | 每个字段标注来源（外部企业数据 / 平台自有 / 第三方），回应调研中「客户不信任没有证据的 AI 输出」这一发现 |
