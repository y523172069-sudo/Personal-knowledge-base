# 管培生成长知识库 HTML Demo 提交说明

## 提交文件

- `管培生成长知识库-内部汇报版.html`

这是内部汇报版的单文件 HTML，已经把页面样式和交互脚本合并到同一个文件中。提交时只需要提交这个 HTML 文件，不依赖外部图片、网络资源、CSS 文件或 JS 文件。

## 使用方式

1. 双击打开 `管培生成长知识库-内部汇报版.html`。
2. 推荐使用 Chrome、Edge 或其他现代浏览器预览。
3. 页面支持本地交互，包括栏目切换、搜索、筛选、详情抽屉和汇报摘要生成。

## 内容口径

- 面向公司内部阶段汇报。
- 重点展示轮岗期间的学习、共创、沉淀和个人思考。
- 不包含外部展示用途的个人材料。
- 不展示公司内部原始材料、客户信息、员工信息、工单截图或内部系统细节。
