# 个人知识库 HTML Demo

这是一个静态 HTML 初版，用于把管培生个人知识库展示为可交互的作品集 Demo。

## 当前包含

- 总览：知识库定位、资产成熟度、重点案例和证据缺口；
- 轮岗时间线：按 2026 年 3 月至 8 月展示轮岗阶段、产出、证据和缺口；
- 沉淀链路：从日常输入到求职资产的流程；
- 能力地图：能力等级、证据强度、下一步补强；
- 证据索引：E-001 至 E-011 的脱敏摘要；
- 简历素材：当前可用素材和成熟度；
- Demo 选题：候选 Demo 的优先级和数据来源。

## 使用方式

直接打开 `index.html` 即可预览。

## 保密边界

- 页面只使用脱敏摘要；
- 不展示公司内部原始材料、客户信息、工单截图和内部系统细节；
- 后续如需公开，需要进一步将公司名称、产品名和具体数据改成通用表达或合成数据。
