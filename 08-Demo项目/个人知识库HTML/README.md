# 个人知识库 HTML Demo

这是一个静态 HTML 初版，用于把管培生个人知识库展示为可交互 Demo。

## 两个入口

- `index.html`：求职版，包含简历素材、Demo 选题和面试复盘相关视角；
- `internal.html`：内部汇报版，只展示轮岗学习沉淀、项目案例、能力地图、证据索引、个人学习心得与思考汇总，不展示求职与简历内容。

## 当前包含

- 求职版：保留简历素材、Demo 选题、项目案例、能力地图和证据索引；
- 内部汇报版：以学习沉淀为主，不展示求职、简历、面试和作品集相关内容；
- 总览：展示轮岗学习定位、重点案例、学习心得与阶段思考；
- 轮岗时间线：按 2026 年 3 月至 8 月展示轮岗阶段、学习内容、阶段产出和个人思考；
- 项目案例：内部汇报版不展示证据 tag，重点展示“共创、成长、思考”；
- 沉淀链路：内部汇报版按时间顺序展示个人成长经历。

## 内部汇报版维护口径

- 重点不是证明业务结果或交付闭环，而是展示轮岗期间的学习、共创和沉淀；
- 3 月标题固定为“人力行政与会议部门轮岗”；
- 4 月标题固定为“销售部门轮岗”；
- 5 月标题固定为“客户成功部门轮岗”；
- 6 月标题固定为“产品与设计部门轮岗”；
- 项目案例优先写清楚：我如何参与共创、我获得了什么成长、我形成了什么思考；
- 不把材料缺口作为页面重点，材料缺口只在后台知识库维护，不放在领导汇报版主界面。

## 使用方式

直接打开 `index.html` 可预览求职版；打开 `internal.html` 可预览内部汇报版。

## 保密边界

- 页面只使用脱敏摘要；
- 不展示公司内部原始材料、客户信息、工单截图和内部系统细节；
- 内部汇报版不展示求职与简历内容；
- 后续如需公开，需要进一步将公司名称、产品名和具体数据改成通用表达或合成数据。
