# 管培生成长知识库

这个项目用于系统整理管培生实习期间的学习、实践和成长证据，并逐步沉淀为可用于求职、作品集和 Demo 制作的个人知识库基建。

## 核心目标

1. **沉淀知识**：把零散信息整理成可复用的方法、模型和判断。
2. **记录实践**：保留任务背景、行动过程、结果和复盘，而不只是结论。
3. **形成证据**：将经历映射为可以被验证的能力证据。
4. **支持求职**：持续生成简历素材、面试案例和 Demo 选题。

## 使用路径

```text
日常输入 → 收集箱 → 学习笔记 / 实践复盘 → 能力证据 → 求职资产
```

从知识库地图开始，路径：`00-导航/知识库地图.md`。该文件当前采用“Codex 内部链接 + 纯文本路径”双轨结构：优先点击绝对本地文件链接；如果仍触发 default apps 或外部程序，则复制路径让 Codex 打开。

需要点击和搜索时使用知识库入口 HTML，路径：`00-导航/知识库入口.html`。如果要检查一份材料是否已经转成复盘、证据、简历或 Demo，使用知识沉淀链路，路径：`00-导航/知识沉淀链路.md`。目录、命名、模板和保密要求见知识库治理规则，路径：`00-导航/知识库治理规则.md`。当前已完成启动访谈第四轮，路径：`07-访谈/00-启动访谈.md`，进入定岗申请与述职准备；阶段状态以访谈文档顶部记录为准。

阶段性建设路线图：`00-导航/知识库阶段建设路线图.md`。当前判断：知识库处于“阶段 4：资产转化与原型化”，正在从学习沉淀转向简历、述职和 Demo 成品。

云端同步说明：`00-导航/云端同步使用说明.md`。用于在多台电脑之间同步知识库主体，并明确哪些原始材料不得进入 GitHub。

当前 Demo 初版：个人知识库 HTML Demo（路径：`08-Demo项目/个人知识库HTML/index.html`）。

## 维护原则

- 先记录事实，再总结观点。
- 一条笔记尽量只解决一个主题。
- 每个重要结论都尽量关联一个真实场景或工作产出。
- 涉及公司机密、客户隐私和内部数据时，必须脱敏。
- 每周整理一次收集箱，每月更新一次能力地图和求职素材。
- 结构性变更遵循知识库治理规则，保持现有路径和链接兼容。
