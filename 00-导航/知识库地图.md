# 知识库地图

## 1. 快速入口

- 知识库入口 HTML（路径：`00-导航/知识库入口.html`）：可搜索、可点击、可复制路径的便捷入口；如 Codex 点击链接异常，回到本地图使用纯文本路径。
- 知识库治理规则（路径：`00-导航/知识库治理规则.md`）：目录、命名、元数据、保密和结构变更的统一规则。
- 启动访谈（路径：`07-访谈/00-启动访谈.md`）：建立个人背景和当前阶段基线。
- 收集箱（路径：`01-收集箱/README.md`）：暂存未经整理的学习和工作信息。
- 待整理清单（路径：`01-收集箱/待整理清单.md`）：尚未形成案例、证据或求职素材的内容。
- 能力地图（路径：`04-能力证据/能力地图.md`）：跟踪能力、案例和证据缺口。
- 证据索引（路径：`04-能力证据/证据索引.md`）：记录原始材料、可证明内容和公开限制。
- 待补证据清单（路径：`04-能力证据/待补证据清单.md`）：集中追踪上线、评分、截图、反馈和业务结果等证据缺口。
- 简历素材池（路径：`05-求职资产/简历素材池.md`）：保存可量化、可验证的经历素材。
- Demo 选题池（路径：`05-求职资产/Demo选题池.md`）：把工作洞察转化为展示项目。
- 个人知识库 HTML Demo（路径：`08-Demo项目/个人知识库HTML/index.html`）：将知识库结构、能力证据和求职资产做成可交互页面。
- 8月底简历与 Demo 交付计划（路径：`05-求职资产/8月底简历与Demo交付计划.md`）：把轮岗结束前的简历、Demo 和述职材料做成可验收计划。
- 定岗定位初稿（路径：`05-求职资产/定岗定位初稿.md`）：当前岗位优先级与能力主线。
- 定岗信息收集清单（路径：`05-求职资产/定岗信息收集清单.md`）：岗位公布后需要确认的信息。
- 述职报告主线初稿（路径：`05-求职资产/述职报告主线初稿.md`）：用项目落地能力串联轮岗经历。

## 2. 内容结构

| 区域 | 用途 | 典型内容 |
| --- | --- | --- |
| `00-导航` | 提供全局入口与治理规则 | 知识库地图、治理规则、跨模块约定 |
| `01-收集箱` | 低成本捕获 | 临时想法、会议收获、术语、待研究问题 |
| `02-管培生学习` | 沉淀认知 | 岗位理解、业务知识、工作方法 |
| `03-实践复盘` | 记录应用 | 任务复盘、项目案例、轮岗总结 |
| `04-能力证据` | 建立能力档案 | 能力地图、反馈、产出、量化结果 |
| `05-求职资产` | 转化为对外材料 | 简历素材、面试案例、作品集、Demo |
| `06-模板` | 保持记录一致 | 学习笔记、工作复盘、项目案例模板 |
| `07-访谈` | 通过问答持续梳理 | 背景访谈、阶段访谈、专题访谈 |
| `08-Demo项目` | 保存可展示项目 | 个人知识库 HTML Demo、后续作品集原型 |

## 3. 每周维护动作

1. 清理收集箱，将内容归入学习或实践区域。
2. 选择一件重要工作，用复盘模板补全背景、行动和结果。
3. 更新一条能力证据，标记缺少的数据或材料。
4. 检查是否出现新的简历素材或 Demo 机会。
