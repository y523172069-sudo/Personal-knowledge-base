# 知识沉淀链路

用途：把零散材料、实践复盘、能力证据、求职资产和 Demo 项目用 Markdown 链接串起来。以后维护时优先按这条链路检查，避免材料散落但没有转化。

## 1. 总链路

```text
原始材料 / 工作记录
→ 收集箱
→ 学习笔记 / 实践复盘
→ 证据索引 / 能力地图
→ 简历素材 / 述职主线 / Demo 选题
→ HTML Demo / 最终展示材料
```

| 阶段 | 作用 | 入口 |
| --- | --- | --- |

## 3. 每周维护链路

每周维护时按以下顺序检查：

1. 先看 [待整理清单](../01-收集箱/待整理清单.md)，判断是否有新材料需要归档；
2. 再看 [实践复盘入口](../03-实践复盘/README.md)，补充本周新增复盘；
3. 然后更新 [证据索引](../04-能力证据/证据索引.md)、[能力地图](../04-能力证据/能力地图.md) 和 [待补证据清单](../04-能力证据/待补证据清单.md)；
4. 如果证据足够，再更新 [简历素材池](../05-求职资产/简历素材池.md)、[述职报告主线初稿](../05-求职资产/述职报告主线初稿.md) 和 [Demo 选题池](../05-求职资产/Demo选题池.md)；
5. 最后记录维护结果到 [最新每周维护记录](../03-实践复盘/每周维护记录-2026-07-09.md)。

原则：证据不足的内容只进入收集箱、复盘或待补证据清单，不进入简历成果。

## 4. 保密链路

```text
内部原始材料
→ 仅本地归档
→ 校验清单记录
→ 脱敏摘要 / 合成数据
→ 简历、述职或 Demo
```

- 原始材料完整性：[原始材料校验清单](../04-能力证据/原始材料校验清单.md)
- 对外限制判断：[证据索引](../04-能力证据/证据索引.md)
- 证据缺口追踪：[待补证据清单](../04-能力证据/待补证据清单.md)
- 治理规则：[知识库治理规则](知识库治理规则.md)

不确定是否能公开时，默认只保留问题类型、方法、个人行动和脱敏后的结果，不展示客户、员工、内部系统、工单号、截图原文和原始数据。
