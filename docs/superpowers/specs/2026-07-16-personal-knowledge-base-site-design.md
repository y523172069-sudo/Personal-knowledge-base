# 管培生成长知识库私密网站设计说明

状态：待用户复核
日期：2026-07-16
目标目录：`08-Demo项目/个人知识库Sites`
内容来源：`08-Demo项目/个人知识库HTML/提交包/管培生成长知识库-内部汇报版.html`

## 1. 项目目标

将现有“管培生成长知识库内部汇报版”建设为可通过私密链接访问的网站，主要供直属领导或带教直接浏览。

使用场景按以下优先级设计：

1. 日常查看成长记录；
2. 阶段性轮岗汇报；
3. 定岗或转正汇报。

第一版采用人工更新：用户提出更新要求后，修改网站的独立内容文件，完成检查并重新发布。第一版不自动同步本地知识库，也不提供网站内编辑。

## 2. 来源与边界

### 2.1 唯一内容来源

第一版只使用选定的内部汇报单文件版。可以在不改变事实的前提下调整文字结构和展示方式，但不得从知识库其他正文、原始材料、内部链接或其他 Demo 版本补充内容。

### 2.2 原文件保护

- 原知识库保持不变；
- 现有 HTML Demo 和提交包保持不变；
- 新网站单独保存在 `08-Demo项目/个人知识库Sites`；
- 网站更新不得反向改写原知识库或现有 Demo。

### 2.3 保密范围

网站采用私密发布，向直属领导或带教提供可直接访问的私密链接。网站不包含公司内部原始材料、客户信息、员工信息、工单截图、内部系统细节或本地文件链接。

## 3. 第一版范围

### 3.1 包含内容

- 总览；
- 轮岗时间线；
- 项目案例；
- 沉淀链路；
- 能力地图；
- 证据索引；
- 当前轮岗阶段；
- 最近成长记录；
- 栏目内筛选；
- 详情抽屉。

### 3.2 不包含内容

- 全站搜索；
- 生成汇报摘要；
- 自动同步本地知识库；
- 网站内编辑；
- 在线数据库；
- 公开发布；
- 从其他知识库文档自动补充内容。

## 4. 整体架构

第一版采用“结构化网站模块＋独立内容层”的组合方式。

```text
网站外壳
├─ 左侧栏目导航
├─ 主内容区
└─ 独立页面模块
   ├─ 总览
   ├─ 轮岗时间线
   ├─ 项目案例
   ├─ 沉淀链路
   ├─ 能力地图
   └─ 证据索引

独立内容层
├─ 当前轮岗阶段
├─ 最近成长记录
├─ 时间线
├─ 项目案例
├─ 沉淀链路
├─ 能力信息
└─ 证据条目
```

页面模块只负责展示和交互；具体知识内容保存在独立内容文件中。后续人工更新优先修改内容文件，不直接改动页面结构。

## 5. 页面与视觉设计

### 5.1 整体方向

- 布局：工作台式；
- 风格：现代黑橙；
- 设备：以电脑端为主要浏览环境；
- 文字口径：事实记录型，重点表达“做了什么、学到什么”；
- 视觉基调：深色导航、白灰内容区、橙色强调；
- 橙色只用于当前状态、选中栏目和重要数字，不作为大面积背景。

### 5.2 导航

左侧固定导航显示六个栏目：总览、轮岗时间线、项目案例、沉淀链路、能力地图、证据索引。当前栏目必须有明确选中状态。较窄的电脑窗口可以收起导航，但第一版不以手机体验为主要目标。

### 5.3 首页信息顺序

1. 当前轮岗阶段：部门、阶段重点和正在学习的事项；
2. 最近成长记录：时间、做了什么、学到什么；
3. 快速统计：轮岗阶段、项目案例、成长记录等数量；
4. 重点项目与阶段思考入口。

首页不显示全站搜索框，也不显示“生成汇报摘要”按钮。

## 6. 页面模块

### 6.1 总览

展示当前轮岗阶段、最近成长记录、快速统计、重点项目和阶段思考入口。第一屏必须优先展示当前轮岗阶段与最近成长记录。

### 6.2 轮岗时间线

按时间顺序展示轮岗阶段、学习重点、参与事项和阶段产出。内容必须来自选定单文件版，不补充外部事实。

### 6.3 项目案例

以卡片展示项目名称、参与内容、学习收获和当前状态。保留栏目内筛选。点击卡片后从右侧打开详情抽屉。

### 6.4 沉淀链路

展示从日常输入到学习、复盘、能力和阶段总结的成长路径，保持当前内部汇报版的内容口径。

### 6.5 能力地图

展示能力名称、当前理解程度、已有学习证据和下一步学习方向。保留栏目内筛选和详情抽屉。

### 6.6 证据索引

展示证据编号、名称、可证明内容、限制和状态。保留栏目内筛选和详情抽屉，不链接本地原始材料。

## 7. 内容模型

独立内容层至少包含以下内容集合：

```text
content/
├─ current-stage
├─ recent-updates
├─ timeline
├─ projects
├─ workflow
├─ abilities
└─ evidence
```

最近成长记录包含以下字段：

- 日期；
- 所属轮岗阶段；
- 做了什么；
- 学到什么；
- 当前状态。

其他内容集合保留当前单文件版已有的标题、说明、状态、限制、关联和筛选字段。内容文件采用可读、可检查的结构化格式，页面不重复保存同一份业务内容。

## 8. 数据流与更新流程

首次建设流程：

```text
内部汇报单文件版
→ 提取现有脱敏内容
→ 按栏目整理为独立内容文件
→ 网站模块读取内容
→ 完整性与保密检查
→ 私密发布
```

后续更新流程：

```text
用户提出更新内容
→ 修改对应内容文件
→ 检查必填字段、关联和保密边界
→ 生成网站
→ 重新私密发布
```

第一版不建立从本地知识库到网站的自动同步链路。

## 9. 异常处理

- 必填字段缺失时停止发布，先修正内容；
- 可选字段缺失时隐藏对应字段，不显示空白卡片；
- 栏目没有内容时显示“暂无记录”；
- 筛选没有匹配项时显示明确的空结果提示；
- 详情内容无法读取时不打开详情抽屉，并保持当前页面可继续使用；
- 技术错误不得直接显示给网站访问者。

## 10. 验证范围

发布前完成以下检查：

- 必填内容字段完整；
- 栏目切换正常；
- 各栏目筛选正常；
- 详情抽屉可打开和关闭；
- 重复条目和失效关联已处理；
- 主要电脑尺寸下没有明显布局溢出；
- 页面中不存在全站搜索或生成汇报摘要入口；
- 页面中不存在本地文件路径或未授权内容；
- 网站能够成功生成并私密发布。

默认不执行额外的浏览器自动点击、截图或多尺寸视觉测试，除非用户后续明确要求。

## 11. 第一版验收标准

第一版满足以下条件时可以交付：

1. 通过私密链接打开网站；
2. 首页第一屏优先展示当前轮岗阶段和最近成长记录；
3. 六个栏目均可正常切换；
4. 栏目内筛选与详情抽屉正常工作；
5. 网站采用工作台式布局和现代黑橙视觉；
6. 内容全部来自选定的内部汇报单文件版；
7. 原知识库和现有 Demo 未被修改；
8. 网站没有全站搜索和生成汇报摘要；
9. 网站未公开发布，也不依赖本地文件链接。
